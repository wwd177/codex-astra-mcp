# Gemini 4 × GPT-6.2 Astra 极速零风险双核协作规范（v1.2）

本技能基于常驻热连接 `codex-astra v1.2.0` 引擎设计，确保 **Antigravity 主控（大上下文主工程师）** 与 **GPT-6.2 Astra（只读红队专家）** 在 **5～15 秒级响应** 下高效交锋、零双写风险、杜绝互相附和（Anti-Sycophancy）。

---

## 1. 核心角色与安全边界

- **Antigravity 主控（你，主工程师）**：
  - 负责 1M 大上下文代码库探索、精准代码切片提取、整体方案落地、文件写入与终端测试验证。
  - **唯一拥有写文件与终端修改权限的一方**，杜绝双写冲突。
- **GPT-6.2 Astra / Sol（经由 `codex-astra` 常驻只读热通道）**：
  - 严格运行在三重锁死的 `read-only` 沙箱，已自动隔离全局重型外部 MCP 与桌面插件。
  - 负责独立盲评、反方挑刺、数理/并发边界推演与真实 Git Diff 缺陷捕获，永不修改本地文件。

| 协作场景 | 推荐 `model` | 推荐 `effort` | 是否传 `cwd` | 典型耗时 |

| **日常快问 / 轻量观点碰撞 / 语法与 API 复核** | `gpt-6.2-sol` | `low` 或 `medium` | **不传 `cwd`**（直接喂切片） | **~5–8s** |

| **高危核心重构终审 / 隐蔽并发死锁 / 深度数理证明** | `gpt-6.2-astra` | `high`（极端疑难才用 `xhigh`） | 按需传入工作区路径 | **~20–45s** |

## 3. 三大极速协作流水线（单轮直达优先，拒绝串行打乒乓）

### 流水线 A：单轮盲评与红队决策（Single-Round Blind / Redteam）
适用场景：技术选型、架构拍板、方案对比。
1. **本地切片与独立判断**：你先利用自身工具读取相关代码（同一回合批量读取），在内心明确你的方案，提炼出**客观背景、约束条件与核心代码切片**。
2. **单轮直调（二选一，不串行跑两轮！）**：
   - **需无偏盲评时**：调用 1 次 `astra_ask`（默认 `effort: "medium"`，不暴露你的倾向结论，不传 `cwd`），让 Astra 独立给出最优解与潜在雷区；
   - **已有明确方案需挑刺时**：直接调用 1 次 `astra_redteam`（传入你的精炼方案与代码切片，默认 `effort: "medium"`），直接获取 `VERDICT` 与 `P0/P1` 反例。
3. **当场收敛或追问**：
   - 90% 场景 **1 轮即收敛**：吸收有事实依据的修正直接落地；若存在核心权衡冲突，禁止和稀泥，直接用对比表向用户呈报 `DEADLOCK`。
   - 仅当关键事实需二次交锋时，传入上轮返回的 `thread_id` 热续接 `astra_ask`（命中缓存，最多追问 1 轮）。

### 流水线 B：构建 → 热连接 Diff 审计 → 闭环（Fast Build & Diff Review）
适用场景：功能实现、Bug 修复、模块重构。
1. **实现与自测**：你在工作区完成代码修改并跑通基础验证。
2. **单次聚焦审计**：
   - Git 仓库改动：调用 `astra_review_diff`（传 `cwd` 与 `focus`，默认 `effort: "medium"`，未提交改动自动走常驻热通道）；
   - 非 Git 目录：调用 `astra_redteam`（传入改动前后关键切片，`effort: "medium"`，省略 `cwd`）。
3. **事实核验与收敛**：对每条 `P0/P1` 意见回读真实代码核验真伪，修复真缺陷并验证通过即交付（最多复审 1 次，防循环拖延）。

### 流水线 C：疑难 Bug 双盲排错（Dual-Blind Root Cause）
适用场景：偶发竞态、隐蔽状态污染、跨进程异常。
1. 提取最小复现条件、报错堆栈与核心函数切片（控制总输入精炼聚焦）。
2. 调用 1 次 `astra_ask`（`model: "gpt-6.2-astra"`, `effort: "high"`，附完整切片），要求其直接输出 **Top 3 根因假设 + 最小证伪实验**。
3. 结合你的第一假设取并集，直接用终端命令/单测快速证伪并完成最小侵入修复。

## 4. 速度与质量黄金铁律

1. **切片投喂免扫盘（头号提速铁律）**：
   - 只要你已读取相关代码，**务必把核心代码切片（含文件名与行号）直接塞进 `prompt` / `proposal`，并省略 `cwd` 参数**！省略 `cwd` 会自动挂载空只读隔离目录并禁止 Astra 启动 PowerShell 扫盘，单次直接省去 10～30 秒沙箱工具往返。
2. **唯一结构化裁决字段**：
   - 红队与 Diff 审计首行固定输出 `VERDICT: LGTM` / `VERDICT: NEEDS_FIX` / `VERDICT: DEADLOCK`，严禁正文中重复出现干扰判定。
